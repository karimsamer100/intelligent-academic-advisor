# Academic Data

This folder contains development academic data derived from official Regulations 2018 and 2023 sources.

The original official PDFs live outside the Git repository and are not copied into this repository.

`normalized/` is **not** automatically academically approved runtime truth. It is development data that remains subject to academic review.

Known unresolved academic conflicts are documented under `review/`.

Critical academic decisions must eventually use approved and verified data only.

The full original Academic Data Foundation delivery remains archived outside the Git repository under `_handoffs/academic-data/` in the intended workspace layout. In this checkout, the supplied ZIP was found at the GP workspace root and was not moved or modified.
