# AI / Developer Start Here

Before doing project work, read:

1. `docs/project/README.md`
2. `docs/project/PROJECT_STATUS.md`
3. `docs/decisions/Project_Decisions.md`
4. `docs/project/PROJECT_LOG.md`

Then inspect the current Git branch/HEAD and the relevant component-specific decision docs.

Use:
- `PROJECT_STATUS.md` for the current truth/state.
- `Project_Decisions.md` for locked project-wide decisions.
- `PROJECT_LOG.md` for recent milestones and how the project reached its current state.

Do not rely on old roadmap/task files as current project status.
Do not invent missing architectural or academic decisions.
If current code conflicts with documentation, surface the conflict instead of silently choosing one.
